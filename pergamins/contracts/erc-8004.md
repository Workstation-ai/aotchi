> Last updated: Chapter 3 (The Deployment)

- **Testnet**: `0x8004A818BFB912233c491871b3d84c89A494BD9e` (chain 97)
- **Mainnet**: `0x8004A169FB4a3325136EB29fA0ceB6D2e539a432` (chain 56)

## Functions Used

| Function | Chapter | Description |
|----------|---------|-------------|
| `register(agentURI)` | Ch.2 | Creates a new agent, mints ERC-721, returns agentId. URI should be `data:application/json;base64,...` |
| `tokenURI(tokenId)` | Ch.2 | Returns the agent's metadata URI |
| `ownerOf(tokenId)` | Ch.2 | Returns the agent owner address |
| `setAgentURI(agentId, newURI)` | Ch.3 | Updates metadata after registration |

## Metadata Format

```json
{
  "type": "https://eips.ethereum.org/EIPS/eip-8004#registration-v1",
  "name": "agent-name",
  "description": "Agent description",
  "image": "",
  "endpoints": [
    {
      "name": "skill-name",
      "endpoint": "https://aotchi.app/agents/agent-name",
      "version": "0.1.0"
    }
  ],
  "registrations": []
}
```

**Important**: Use `endpoints` field (not `services`) for 8004scan compatibility.

## Implementation

`src/infra/erc8004.ts` — viem-based wallet and public clients for BSC.

- Wallet generated once, stored at `~/.aotchi/wallet.json`
- `getOrCreateWallet()` — deterministic, creates if not exists
- `registerAgent()` — writes register, waits for receipt, parses logs for token ID
- `setAgentURI()` — writes update, waits for receipt
- `verifyAgent()` — reads ownerOf + tokenURI to verify on-chain

## 8004scan

- **URL pattern**: `https://8004scan.io/agents/bsc-testnet/{tokenId}`
- API: `https://8004scan.io/api/v1/public/agents/{chainId}/{tokenId}`
- Chain IDs: 97 (testnet), 56 (mainnet)
- Testnet agents visible but limited UI
- Re-indexing takes ~minutes after metadata update
